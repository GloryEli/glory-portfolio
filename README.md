# Dual-Track Professional Portfolio | Glory Elizabeth Akoto

Live Site: [https://GloryEli.github.io/glory-portfolio/](https://GloryEli.github.io/glory-portfolio/)

## Overview

This repository contains the personal dual-track portfolio website for **Glory Elizabeth Akoto**. It bridges two primary professional domains: full-stack AI engineering & consultancy and fine art creative direction under Glory Blooms Gallery.

## Key Features

- **AI Engineering Track:** Showcases production system deployments (Academic Bloom), machine learning expertise, startup leadership at Liz Inspired Technologies, and technical stack capabilities.
- **Fine Art Track:** Features textured impasto fine art collections, exhibition milestones, and gallery creative direction under Glory Blooms.
- **Responsive Navigation:** Mobile-friendly drawer navigation, smooth anchor scrolling, and email copy-to-clipboard integration with standard `mailto:` fallbacks.

## Technology Stack

- **Languages:** HTML5, CSS3, JavaScript
- **Styling:** Tailwind CSS (Custom Color System)
- **Icons:** FontAwesome 6.4
- **Hosting:** GitHub Pages (Deploys automatically from `master` branch)

## Quick Start (Local Inspection)

```bash
# Clone the repository
git clone https://github.com/GloryEli/glory-portfolio.git


# Navigate to project folder
cd glory-portfolio

# Serve locally
python -m http.server 8000
```
